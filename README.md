## Problem（背景与问题）

栖霞山红枫节需要年轻化的宣传内容，把「萌猫 + 枫叶」的治愈感传到短视频平台。传统宣传片靠实拍：成本高、周期长、一条片子只能出一个版本，很难快速铺开多条传播素材。

## Why AI（为什么用 AI 做）

把「实拍才能出片」变成「脚本 + 提示词就能出片」。全片 **85% 镜头由 AI 生成**（文生视频 + 图生视频），只用 15% 实拍素材做锚点，就能在短周期内产出一条 2 分半主片 + 三条竖屏切片，一套素材多平台复用。

## Architecture（生成管线）

```mermaid
flowchart LR
    A[脚本 / 分镜<br/>Claude Code + 豆包] --> B[图像生成<br/>豆包 / 即梦 / NextLabs]
    B --> C[视频生成<br/>NextLabs / 豆包]
    C --> D[音乐 / 配音<br/>Suno + 博主混音]
    D --> E[后期剪辑<br/>剪映]
    E --> F[成片<br/>1 主片 + 3 切片]
```

## Skills（能力拆解）

- **脚本**：Claude Code + 豆包 —— 叙事脚本与分镜
- **图像**：豆包 / 即梦 / NextLabs —— 生成猫猫与枫叶关键帧
- **视频**：NextLabs / 豆包 —— 文生视频 + 图生视频
- **音频**：Suno —— AI 配乐；抖音博主混音版做配音
- **后期**：剪映 —— 剪辑、字幕、节奏

## Eval（成果）

- **1 条** 2 分 42 秒横屏主宣传片（16:9，1080p）
- **3 条** 6–15 秒竖屏切片（适配抖音传播）
- AI 生成镜头占比 **85%**，实拍 **15%**（3 张官方资源包 + 1 张自拍彩虹明镜图）
- 素材均已授权；猫形象参考景区奶皮子酸奶上的猫形象，AI 生成内容均为原创

## Design Decisions（设计决策）

- **猫 + 枫叶组合**：红枫节主打视觉是枫红，但纯风景缺记忆点，萌猫作为情感锚点制造「治愈感」和「转发欲」
- **横屏主片 + 竖屏切片**：主片服务官方大屏宣发，切片适配抖音/视频号竖屏传播，一套素材两吃
